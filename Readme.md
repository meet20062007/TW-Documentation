## Areas of Study

### 1. LaTeX – Document Preparation

The LaTeX section contains assignment work and learning notes on producing well-structured, professionally typeset documents. The topics include:

- Mathematical notation and equations
- Tables, figures, and cross-references
- Advanced formatting and custom commands
- Graphics and diagrams using TikZ
- Structuring professional documents

The `LaTeX/` directory contains the main guide and folders for Assignments 1 through 6. Individual assignment folders hold their relevant `.tex` source, learning notes, and bibliography files where applicable.

### 2. Beamer – Presentations

The Beamer material focuses on creating slide presentations with LaTeX. It covers:

- Professional themes and colour schemes
- Mathematical typesetting in slides
- Overlay specifications and animations
- Blocks and two-column layouts
- Generating a table of contents

The `Beamer/` folder contains the presentation source file (`beamer.tex`) and the accompanying `learning.md` notes.

### 3. Doxygen – Source Code Documentation

The Doxygen section explores automatic documentation generation from source code. Its learning topics include:

- Special comment syntax for API documentation
- Class diagrams and call graphs
- HTML and PDF documentation output
- Cross-referenced documentation
- Code examples and usage guides

The `Doxygen/Assignment7/` directory contains the C++ source and header files, the Doxygen configuration file (`Doxyfile`), the compiled application, and assignment learning notes. The parent `Doxygen/` directory contains its README.

### 4. Git and GitHub – Version Control

This section records practical work with version control and collaborative development, including:

- Initializing and managing repositories
- Branch creation, switching, and merging
- Remote repository operations
- Collaboration through pull requests and code review
- A comprehensive Git command reference

The `Git-Github/` folder contains the section README, Assignment 9 notes, and `commands.md` reference.

## Course Goals

The repository supports the main objectives of the course:

1. Develop proficiency with technical documentation tools.
2. Learn how documents can be automated and generated.
3. Understand version control systems and their workflows.
4. Apply good practices in technical writing.
5. Produce clear and professional technical documents.

## How the Repository Is Organized

Work is grouped by tool or subject, with assignment-specific material kept in its corresponding folder. Depending on the assignment, a folder may contain:

- **README files** describing the topic or assignment
- **Learning notes** recording concepts and outcomes
- **Source files** used to create documents or demonstrate a tool
- **Reference files** such as bibliography databases and configuration files
- **Examples** illustrating syntax and practical usage

## Documentation Approach

The repository brings together focused guides and practical examples. Its documentation aims to be:

- **Self-contained:** each section provides information relevant to its subject.
- **Practical:** examples demonstrate syntax and usage.
- **Consistent:** assignments are grouped by topic and supported by learning notes.
- **Reference-friendly:** command lists, source examples, and best-practice notes are kept together.

The repository includes assignment source and support files as shown in the directory tree, alongside the written documentation.
