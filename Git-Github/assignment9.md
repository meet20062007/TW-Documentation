| Area | Concepts covered |

## 5. Command Practice

### Repository setup

```bash
git init
git clone <url>
```

### Basic workflow

```bash
git status
git add .
git commit -m "message"
```

### Branching

```bash
git branch feature-branch
git checkout feature-branch
git merge feature-branch
```

### Remote operations

```bash
git remote add origin <url>
git push origin main
git pull origin main
```

### Viewing history

```bash
git log
git log --oneline --graph
```

## 6. Main Takeaways

- Git provides complete version history.
- Branching enables parallel development.
- GitHub facilitates team collaboration.
- Commit messages are important documentation.
- Regular commits help track progress.
- Merge conflicts are normal and manageable.
