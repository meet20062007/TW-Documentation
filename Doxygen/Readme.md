# Calculation App — Doxygen Documentation

## Overview

This project is a small multi-file C++ application that performs a power calculation and uses a logging component to report the calculation process. The project is documented with **Doxygen**, which extracts specially formatted comments from source code and generates HTML and LaTeX/PDF reference documentation.

## Build and run the application

From the directory containing `main.cpp`, `Logger.h`, and `CalculationEngine.h`, compile with:

```bash
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o calculation_app
```

If compilation succeeds, run:

```bash
./calculation_app
```

The output should be similar to:

```text
[INFO] Starting power calculation.
[INFO] Power calculation completed.
Result: 8
```

## Generate documentation with Doxygen

Make sure Doxygen is installed and the project contains a configured `Doxyfile`. Generate the documentation with:

```bash
doxygen Doxyfile
```

In this workflow, the generated output is placed in a folder named `docs`.

### View the HTML documentation

```bash
xdg-open docs/html/index.html
```

### Generate and view the PDF

Move into the generated LaTeX directory and build the PDF:

```bash
cd docs
cd latex
make pdf
```

Open the generated reference manual:

```bash
xdg-open refman.pdf
```

If your Doxyfile configures a different output directory or Makefile target, use the paths and target generated by your configuration.

## Project files

| File | Purpose |
|---|---|
| `main.cpp` | Application entry point; starts the power-calculation workflow. |
| `Logger.h` | Declares the logging class and log-level enum. |
| `CalculationEngine.h` | Declares the calculation engine and its power-calculation operation. |
| `Doxyfile` | Configures Doxygen input, output, and generated formats. |

## Documentation workflow

1. Add Doxygen-style comments to the source files, documenting the main page, classes, enum values, constructor, parameters, and return values.
2. Configure HTML and LaTeX output in `Doxyfile`.
3. Run `doxygen Doxyfile`.
4. Browse `docs/html/index.html`.
5. Build the PDF from the generated `docs/latex` directory.

## Notes

- The compiler command uses C++17 and enables common compiler warnings.
- The example output is illustrative; exact formatting depends on the implementation.
- The HTML and PDF manuals are generated from the Doxygen comments and configuration. Regenerate them whenever the documented API changes.
