\begin{frame}{Document Formatting in LaTeX}

\begin{itemize}
\item LaTeX is used to create professional and well-structured documents.
\item The document uses the \texttt{report} document class.
\item Page size is set to A4 with a 1-inch margin.
\item Different packages are used for formatting:
\begin{itemize}
\item \texttt{xcolor} -- adds colors.
\item \texttt{sectsty} -- formats headings.
\item \texttt{fancyhdr} -- customizes headers and footers.
\end{itemize}
\end{itemize}

\end{frame}

% Slide 3: Headings and Page Style

\begin{frame}{Headings and Page Style}

\begin{itemize}
\item Chapter, section, and subsection headings can be customized.
\item Different colors and font styles improve readability.
\item The \texttt{fancyhdr} package is used to create custom headers and footers.
\end{itemize}
